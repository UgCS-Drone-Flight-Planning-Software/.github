# .github
UgCS — профессиональная наземная станция и платформа планирования полётов для беспилотных аппаратов. Предназначена для создания автоматических маршрутов, waypoint-миссий, картографических и инспекционных заданий, работы с рельефом, телеметрией и управления совместимыми UAV различных производителей.
