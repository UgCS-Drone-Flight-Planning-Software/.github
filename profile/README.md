## Обзор проекта

**UgCS (Universal Ground Control Software)** — программная платформа для планирования и выполнения полётных миссий беспилотных аппаратов. Она ориентирована на профессиональное применение UAV и предоставляет инструменты для подготовки маршрутов, работы с картами, контроля полёта и создания специализированных заданий для аэросъёмки, инспекций и других операций.

В отличие от простого waypoint-планировщика, UgCS позволяет создавать более сложные маршруты с учётом характеристик аппарата и местности. Пользователь может работать с высотой, скоростью, действиями на маршрутных точках и различными шаблонами полётных заданий.

UgCS поддерживает работу с беспилотными платформами различных производителей. Конкретные возможности управления, телеметрии и передачи миссий зависят от модели UAV, используемого автопилота и версии программного обеспечения.

## Основные возможности

| Функция | Назначение |
|---|---|
| **Mission Planning** | Создание и редактирование полётных заданий |
| **Waypoints** | Построение маршрутов из последовательности точек |
| **Area Scan** | Планирование автоматического облёта территории |
| **Photogrammetry** | Подготовка маршрутов для аэрофотосъёмки |
| **Terrain Following** | Планирование маршрута относительно рельефа |
| **Telemetry** | Контроль доступных параметров UAV |
| **Map View** | Работа с маршрутами и объектами на карте |
| **Flight Parameters** | Настройка высоты, скорости и параметров маршрута |
| **Geofencing** | Использование пространственных ограничений |
| **Multiple UAV Platforms** | Работа с различными поддерживаемыми дронами |
| **Mission Import / Export** | Работа с поддерживаемыми форматами полётных заданий |

UgCS может использоваться для построения как относительно простых маршрутов между waypoint, так и автоматизированных схем облёта больших территорий.

## Картография, фотограмметрия и Terrain Following

Одно из основных направлений применения **UgCS** — подготовка полётов для сбора геопространственных данных. При картографической съёмке можно создавать систематические маршруты над выбранной областью, задавая параметры, необходимые для получения последовательности перекрывающихся снимков.

Такие маршруты применяются при создании ортофотопланов, 3D-моделей местности и других материалов фотограмметрической обработки. Итоговое качество данных зависит не только от маршрута, но и от камеры, высоты полёта, перекрытия изображений и условий съёмки.

Для работы над местностью со значительными перепадами высот UgCS предоставляет инструменты планирования с учётом рельефа. Это помогает проектировать траекторию с более стабильной относительной высотой над поверхностью вместо использования одной абсолютной высоты для всего маршрута.

## UAV и совместимые платформы

| Категория | Применение |
|---|---|
| **DJI Enterprise** | Работа с поддерживаемыми профессиональными UAV |
| **ArduPilot** | Интеграция с поддерживаемыми конфигурациями |
| **PX4** | Работа с совместимыми MAVLink-системами |

| **Fixed-Wing** | Поддержка определённых самолётных платформ |
| **Telemetry** | Мониторинг аппарата при поддержке конкретной модели |
| **GPS / GNSS** | Координатная навигация и выполнение маршрутов |

Список поддерживаемых аппаратов и доступных функций различается между моделями. Для одного UAV могут быть доступны автоматическая загрузка миссии и телеметрия, тогда как для другого набор возможностей может быть ограничен особенностями SDK или протокола производителя.

Перед подготовкой проекта рекомендуется проверить поддержку конкретной модели дрона и установленной на нём версии firmware.

## Профессиональные сценарии использования

UgCS применяется там, где необходимо заранее подготовить воспроизводимый маршрут полёта. Это может быть картографирование территории, фотограмметрия, обследование протяжённых объектов, инспекция инфраструктуры или регулярный сбор данных над одной и той же областью.

Для больших проектов особенно полезна возможность заранее создать миссию на компьютере, проверить геометрию маршрута и сохранить проект для дальнейшего использования. Это позволяет отделить этап планирования от непосредственной работы аппарата в полевых условиях.

При подготовке автоматической миссии необходимо учитывать ограничения конкретного UAV, запас аккумулятора, связь, рельеф, препятствия, погодные условия и действующие требования к эксплуатации беспилотных аппаратов.

## Быстрый старт

1. Запустите **UgCS** и создайте новый проект.
2. Выберите поддерживаемую модель беспилотного аппарата.
3. Откройте необходимую территорию на карте.
4. Создайте маршрут вручную или выберите подходящий тип автоматического задания.
5. Настройте высоту, скорость и доступные параметры миссии.
6. При необходимости настройте Area Scan или другой шаблон маршрута.
7. Проверьте рельеф и ограничения в районе выполнения задания.
8. Проверьте длину маршрута и предполагаемую продолжительность полёта.
9. Передайте миссию на совместимый UAV предусмотренным для него способом.
10. Перед запуском ещё раз проверьте маршрут, состояние аппарата и параметры безопасности.
